# 威胁模型与边界

## 资产与信任

保护资产：SSH/应急管理可达性、现有防火墙规则、主机业务可用性、API 凭据、动作授权和审计证据。只操作用户授权主机，不扫描、攻击或控制第三方设备。

信任：Linux 内核、安装后的 root-owned 程序/策略、管理员、受信日志生产者。日志内容仍是攻击者可影响的数据。普通观察用户、网络客户端、模型返回、HTTP 错误内容、事件 payload 都不受信。root/内核已失陷不在本 MVP 防护范围内。

| 威胁 | 实际控制 | 剩余风险 |
|---|---|---|
| 日志/模型提示词注入 | 丢弃全部原始文本；只发送枚举、IP、数字、时间、摘要；输出严格字段；无 tool/Shell/API URL 控制权 | 攻击者仍可诱导模型判断；模型不是授权依据 |
| 模型要求提权/任意命令 | worker 不允许 root AI；broker 不导入模型模块；固定二进制/参数；生成规则只允许 IP、整数、常量 | root 安装源/依赖被篡改仍可破坏系统 |
| 伪造提案或审批 | root 从固定本地日志重读；重算完整提案/策略摘要；显式人工确认或 root 限时 grant | 摘要用于绑定内容，不证明管理员身份；root 身份由 OS 保证 |
| SSH 误封 | 管理 CIDR+端口 return、检查有效 sshd 配置、保护当前 SSH peer、保留 established 流 | 代理/端口映射/socket activation 需人工登记；原系统防火墙也可能封 SSH |
| 伪造攻击流量借机封别人 | 规则 allowlist、两个 flow、本机目的、时效、TTL、数量及频率上限 | 双 flow 不等于双传感器，也不证明非伪造；UDP spoof、NAT/共享出口仍有误伤风险 |
| UFW/firewalld 重载冲突 | 检测安装/规则就拒绝接管；其他专用表指纹漂移拒绝执行 | 外部 root 管理器可在检查后竞态改动规则；无跨管理器原子锁 |
| 崩溃/掉电/重试 | 持久意图、原子 JSON rename、fsync、root 文件锁、内核 TTL、恢复时回滚未完动作 | 磁盘满/只读可阻断审计和回滚；有限内核 TTL 是最终界限 |
| API 失联、预算耗尽、JSON 损坏 | 五分钟熔断、不重试、不自动切付费服务；人工/已授权确定性规则继续可用 | 上游服务已接受但超时的调用可能收费；预留不退还 |
| 模型虚构证据/超置信 | 必须引用完整已知证据 ID；严格概率范围；阈值、反对否决 | 自报 .99 不是统计校准；不能据此承诺 99% 正确 |
| 凭据泄漏 | 只用环境变量、TLS固定端点、禁重定向/环境代理、无正文错误日志 | 同 UID 恶意进程/主机管理员仍可能读取环境；事件 IP/时间会发给所选供应商 |
| 审计篡改 | SHA-256 前向链和 root 私有 SQLite；调用前验证链 | 本地链不抗 root 重写/截断，需外部只追加日志服务才能强化 |
| 本地资源耗尽 | 每批2万行、行64KiB、可信日志尾4MiB、最多32条证据、模型输出/响应/超时限制、集合1024元素 | 长期数据库/审计无自动保留策略；需监控磁盘并归档 |

## 安全降级

默认失败是“不新增封禁”，保留现有系统防火墙；并不意味着打开原规则。新块失败时仅回滚该块；从不使用全局 `flush ruleset`。遇到所有权/结构不明时宁可停止自动写入，有限 TTL 继续在内核运行。进程退出不会造成永久黑名单。

root 只接受策略中允许的动作，不能更改系统默认 policy、重写 NAT、设置永久 TTL、按 CIDR 大范围封禁或关闭 SSH。源 IP 临时封禁可能影响该出口下其他用户，因此仅给验证过的低误报规则开放限时自动授权。

## 生产化缺口（没有伪装为已完成）

- 本次没有真实 Linux 内核/云 API/Ollama 环境验证；必须先执行隔离内核测试和供应商小样本回放。
- 没有经过红队、安全审计、误报率/召回率评估；多模型独立供应商不等于统计独立。
- 无完整 SOC、跨主机传感器、TCP 握手可信度判定、外部威胁情报、业务健康探针或远程可达性验证。`verify` 是内核集合/规则结构确认，不是外部 SSH 登陆测试。
- Suricata 的安装、规则下载、捕获接口、日志轮转、日志权限由管理员维护；只支持 EVE alert 和已经结构化的 log-rule，不直接解析任意 syslog 文本。
- 没有持久化整套系统规则、自动开启服务、重启自动接管、UFW/firewalld 并行执行保证。需要恢复时人工核验所有权。
- 模型 budget 为估算与调用限额；实际账单须在供应商端核查。端点不可改成自定义代理；企业代理接入需要单独审计实现。
- 暂不提供可被非 root 调用的特权 daemon/sudoers；自动循环只能由管理员明确启用的固定 systemd 服务运行。
